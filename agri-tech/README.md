# AgriTech - Precision Agriculture Platform

A web-based agricultural monitoring system using satellite imagery, weather data, and AI.

## Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js + Express
- **Database:** MongoDB
- **APIs:** Open-Meteo (Weather), Sentinel-2 (Satellite)
- **AI:** TensorFlow.js

## Quick Start

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
npm install
node server.js
```
